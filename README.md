# بوت أذكار الصباح والمساء 🌸

بوت تيليجرام تفاعلي متكامل للأذكار النبوية اليومية بحصن المسلم، مصمم بأزرار سفلية تفاعلية (ReplyKeyboardMarkup) لسهولة الاستخدام، مع عداد ذكي لكل ذكر وسبحة إلكترونية وتنبيهات يومية مجدولة.

---

## 🌟 المميزات
- **🌅 أذكار الصباح و 🌙 أذكار المساء:** الأذكار الصحيحة كاملة مع التكرار والفضل.
- **🔢 عداد تكرار ذكي:** زر تفاعلي ينقص التكرار المتبقي حتى اكتمال الذكر ثم ينتقل تلقائياً للذكر التالي.
- **😴 أذكار النوم و 🕌 أذكار بعد الصلاة:** أدعية وأذكار إضافية مأثورة.
- **📿 السبحة الإلكترونية:** عداد تسبيح حي مع أهداف، إمكانية التبديل بين الأذكار وحفظ مجموع التسبيحات.
- **📊 إحصائيات الإنجاز:** تتبع عدد مرات إتمام أذكار الصباح والمساء وإجمالي التسبيحات.
- **🔔 تنبيهات يومية مجدولة:** تذكير تلقائي صباحاً (06:00 ص) ومساءً (05:00 م) بتوقيت مكة المكرمة.
- **📱 تحكم سفلي مريح:** أزرار ReplyKeyboardMarkup ثنائية الأبعاد بدون فوضى الأزرار الشفافة.

---

## 🚀 طريقة التشغيل

### محلياً (ويندوز):
1. ضع توكن البوت في ملف `token.txt` داخل هذا المجلد (أو ضعه في متغير البيئة `TELEGRAM_TOKEN`).
2. اضغط مرتين على ملف `run_bot.bat` لتشغيل البوت فوراً.

### أو عبر الطرفية:
```bash
pip install -r requirements.txt
python bot.py
```
